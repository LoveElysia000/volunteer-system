## DML

用于存放数据初始化、回填与修复 SQL。

### 执行顺序（推荐）

1. `dml_v1.0.0.sql`
   - 作用：补唯一索引并提供重复数据检查查询。
   - 备注：如果索引已存在，`ALTER TABLE ADD UNIQUE KEY` 可能报错，可按脚本注释忽略。
2. `dml_v1.1.0.sql`
   - 作用：初始化 `level_rules` 等级规则（可重复执行）。
3. `dml_v1.3.2_rbac.sql`（推荐，单文件）
   - 作用：一次执行完成 RBAC 角色、权限、角色权限初始化（空库版）。
   - 备注：脚本已精简，不包含历史数据回填语句。

### 维护约定

- 优先保持幂等（可重复执行）。
- 新增 DML 文件建议使用版本号命名：`dml_vX.Y.Z.sql`。
- 对可能影响已有数据的语句，在文件头部写清前置条件与适用范围。
